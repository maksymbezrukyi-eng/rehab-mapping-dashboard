# Geographic enrichment

`kse_hromada_geography.csv` is a minimal, reviewable extract of the public
KSE Loc Data Hub `data/derived/full_dataset.csv`. It contains only administrative
identifiers, hromada-centre coordinates and the existing travel-time field.

- Source: https://github.com/kse-ua/KSE-Loc-Data-Hub
- Source file: `data/derived/full_dataset.csv`
- License: MIT (repository license)
- Dashboard use: centre coordinates and derived straight-line distances only

The verified rehabilitation-provider workbook remains the authoritative source
for provider and service counts. The enrichment extract does not overwrite it.
